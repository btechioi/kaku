## 🐧 Overview

A minimalist, functional NixOS environment built with the philosophy of constant refinement and transformation — kaku emphasizes aesthetic harmony and technical excellence through the declarative power of Nix flakes.

---

## 🛠️ Structure

- **home/** — Home-manager profiles
- **hosts/** — Host-specific configurations
- **lib/** — Custom Nix library functions
- **pkgs/** — Custom package derivations
- **system/** — System-level NixOS config
